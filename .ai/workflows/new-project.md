# New Project Workflow
1. Confirm empty/genuinely new.
2. Detect language/framework/version/runtime/package manager/database/UI ecosystem.
3. Identify users, roles, requirements and core workflows.
4. Establish architecture and directory conventions.
5. Establish database/migrations.
6. Establish authentication/authorization.
7. Establish UI/design system/component library.
8. Establish responsive/accessibility expectations.
9. Establish audit/logging.
10. Establish testing.
11. Establish deployment/environment assumptions.
12. Populate `.ai/memory` and `.ai/planning`.
13. Populate `.ai/state`.
14. Create an implementation plan.
15. Only then begin broad implementation.
Do not generate an entire system blindly from one vague prompt.
