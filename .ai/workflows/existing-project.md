# Existing Project Workflow
1. Do NOT assume architecture.
2. Inspect structure and dependencies.
3. Detect actual stack/version/runtime/package manager.
4. Map routes/modules, database/migrations, auth/roles, UI/components, tests/build, logs/audit and deployment.
5. Read relevant `.ai` context.
6. Record discovered facts.
7. Identify smallest relevant change.
8. Plan before substantial implementation.
9. Preserve working architecture and conventions.
10. Verify requested behavior and likely regressions.
Never restructure merely to match the template.
