# Coding Rules

- Follow actual framework conventions and existing project patterns.
- Make the smallest coherent change; avoid unrelated refactors.
- Reuse existing utilities, components, services, and the project's selected component library.
- Discover and consult relevant installed global skills before substantial engineering work.
- Validate external input and handle errors visibly.
- Keep secrets out of source control and project memory.
- Do not silently swallow errors or claim checks not run.
- Preserve existing behavior unless a change is intentional and approved.
- After meaningful changes, follow `.ai/workflows/memory-update.md` and verify documentation writes.
